## Domain Knowledge

Category-specific API rules and gotchas:

- ADD SHAPE — Use diagram.AddMaster(stencilPath, masterName) to load a master, then diagram.AddShape(pinX, pinY, width, height, masterName, pageIndex) to add the shape. Returns long shape ID.
- Retrieve shape after adding: Shape shape = page.Shapes.GetShape(shapeId); (cast long to int if needed)
- Set shape text: shape.Text.Value.Add(new Txt("text here"));
- Set shape type: shape.Type = TypeValue.Shape;
- Set shape style: shape.TextStyle = diagram.StyleSheets[index];
- RETRIEVE SHAPE INFO — Iterate page shapes: foreach (Aspose.Diagram.Shape shape in page.Shapes); Access shape.ID, shape.Name, shape.Master.Name.
- COPY SHAPES — Copy all shapes from source to new diagram: load source, add masters with diagram.AddMaster(), copy themes with newDiagram.CopyTheme(srcVisio), copy pagesheet with newDiagram.Pages[0].PageSheet.Copy(srcPage.PageSheet), then add each shape to newDiagram.Pages[0].Shapes.Add(shape).
- Copy single shape to another instance: newShape.Copy(diagram.Pages[0].Shapes[0]); then set newShape.ID and newShape.XForm.PinX/PinY.
- READ SHAPE PROPERTIES (custom/Props) — Iterate shape.Props: foreach (Prop property in shape.Props) { Console.WriteLine(property.Label.Value + ": " + property.Value.Val); }
- Read property by name: Prop property = shape.Props.GetProp("Name1");

## Developer Q&A

Frequently asked questions about **Working With Shapes** in **Aspose.Diagram for .NET**:

**Q: How do I get started with Working With Shapes in Aspose.Diagram for .NET?**

A: Add a reference to `Aspose.Diagram.dll` (v26.7.0), include `using Aspose.Diagram;` and `using Aspose.Diagram.Saving;`, then use `Diagram diagram = new Diagram("input.vsdx");` to load a file. All examples in this category target `net8.0`.

**Q: Why do I get CS1674 when using `using (Diagram diagram = ...)`?**

A: `Diagram` does not implement `IDisposable` in Aspose.Diagram for .NET. Remove the `using` statement and declare the variable normally: `Diagram diagram = new Diagram("input.vsdx");`

**Q: Why does my code fail with CS0117 on `SaveFileFormat.VSDX`?**

A: `SaveFileFormat` enum members use PascalCase in Aspose.Diagram for .NET. Use `SaveFileFormat.Vsdx` (not `VSDX`). The same applies to all formats: `SaveFileFormat.Pdf`, `SaveFileFormat.Png`, `SaveFileFormat.Svg`.

**Q: Why do I get CS0029 when assigning `true` to a BOOL property?**

A: Aspose.Diagram uses its own `BOOL` enumeration type, not C# `bool`. Use `BOOL.True` and `BOOL.False` instead of plain `true`/`false` for all Aspose.Diagram BOOL properties.

**Q: How do I retrieve a Shape object after calling `diagram.AddShape()`?**

A: `diagram.AddShape()` and `page.AddShape()` return a `long` shape ID, not a Shape object. Retrieve the shape using: `Shape shape = page.Shapes.GetShape(shapeId);`

**Q: How do I get the width and height of a shape?**

A: Use `shape.XForm.Width.Value` and `shape.XForm.Height.Value` — direct `shape.Width` and `shape.Height` properties do not exist in Aspose.Diagram for .NET.
